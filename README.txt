UNDANGAN AQIQAH DIGITAL

Struktur:
- index.html : isi undangan
- style.css  : seluruh desain dan tata letak
- script.js  : tempat fitur interaktif tambahan
- img/       : tempat foto dan ornamen

CARA MENGGUNAKAN:
1. Ekstrak folder undangan-aqiqah.
2. Buka folder tersebut di Visual Studio Code.
3. Buka index.html di browser (atau gunakan Live Server).
4. Ganti tulisan "Nama Bayi", "Nama Ayah", "Nama Ibu",
   tanggal, waktu, dan alamat pada index.html.
5. Simpan foto bayi di folder img dengan nama foto-bayi.jpg.
   Jika memakai nama/format lain, ubah atribut src pada tag img di index.html.

Catatan:
- Foto placeholder akan muncul jika foto-bayi.jpg belum tersedia.
- Font dekoratif diambil dari Google Fonts, sehingga perlu koneksi internet.
- Tidak menggunakan framework atau library tambahan.
